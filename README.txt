PORTFOLIO ASSIGNMENT - BEFORE SUBMISSION

1. Open index.html in your browser to preview the website.
2. Replace [STUDENT ID] in the index.html title with your actual student number.
3. Replace YOUR_UNIVERSITY_EMAIL@cit.just.edu.jo with your actual JUST email address.
4. Add your professional photo in the images folder and name it profile-placeholder.jpg.
   Use a JPG image. Keep the exact filename, or update the image src in index.html.
5. Check your academic level. The assignment sheet specifies "Fourth Year"; change it if your actual level differs.
6. Review the name, major, skills, technologies, and future-goals paragraph so they accurately represent you.
7. Upload all project files and the images folder to GitHub Pages. Keep index.html at the repository root.
8. Submit only the published website URL on E-learning, as stated in the assignment.

NOTE:
The contact form validates the fields and displays the required success alert. It does not send/store messages on a server; the assignment only asks for validation and a success alert.
